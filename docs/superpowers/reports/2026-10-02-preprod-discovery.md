# 预发 Gateway、Sidecar 与厂商回调验收准备

日期：2026-10-02。对应[稳定版升级规格](../specs/2026-09-29-openclaw-2026-9-6-upgrade.md)尚未完成的生产环境证据。用户已选择先在本地测试，实际运行结果见[本地 Gateway、Sidecar 与回调复验](2026-10-02-local-gateway-sidecar-callbacks.md)；本文保留未来外部环境的入口清单。

## 当前环境发现

| 对象 | 本机发现 | 预发验收状态 |
|---|---|---|
| Gateway | 存在端口 18789 的个人 OpenClaw Gateway；插件仓库另有隔离 E2E profile | 未发现独立预发地址、profile 或访问凭据；个人 Gateway 不用于验收 |
| OpenMem Sidecar | 本机源码与已通过的隔离 E2E Sidecar 启动器 | 未发现长期运行的预发 Sidecar 或受保护 HTTPS 入口 |
| 厂商 | 本机仅可见 `WECOM_WEBHOOK_URL` 环境变量名；没有可识别的测试租户与回调入口清单 | 不能把变量存在等同于平台测试授权或真实回调成功 |
| 部署入口 | Docker 可用；没有可用的 Kubernetes context 或本项目预发部署清单 | 尚无可确认的预发部署目标 |

## 验收入口与证据

| 边界 | 需要的预发资源 | 最小可观察结果 |
|---|---|---|
| Gateway ↔ Sidecar | 独立 Gateway 地址/管理凭据、OpenMem HTTPS 基址、认证代理的密钥管理引用、隔离数据目录与单写入者声明 | Gateway 只连接指定 Sidecar；未授权请求被拒绝；Agent Turn、提交、重启后召回和幂等重复提交保留相同产物 ID |
| Sidecar 故障恢复 | 可重启的预发实例、专用测试会话与日志/存储只读观察入口 | 在提交阶段重启后，同一 session 可恢复；归档、事实记忆、索引与终态一致，无重复产物。真实断电和多写入者须分别验收 |
| 企业微信 Agent/Bot、企业微信客服 | 测试企业、回调 URL 配置权、测试用户、可轮换的 Token/AESKey 引用 | 官方平台 URL 校验和签名/解密成功；测试消息完成一次 Agent Turn 与回复；重复投递和重启不重复发送 |
| 抖音、美团 | 测试应用/门店、平台回调 URL 配置权、签名密钥引用、测试事件 | 平台实际通知/消息被验签并持久确认；无效签名拒绝；重复事件不产生重复处理。美团仅验证通知和消息回调，不自动执行业务写 API |
| 微信 iLink、微信 iPad 桥接 | 专用测试账号及协议/桥接服务入口 | 平台或桥接服务实际消息进入 Agent，回复送达测试账号；重连和重放边界有记录。两者不应被误记为 HTTPS webhook 回调 |

## 执行约束

- 只使用测试租户、测试用户和专用数据目录。凭据保留在既有密钥管理器或环境变量，不写入仓库、报告或命令输出。
- OpenMem Server 没有原生请求鉴权；非 loopback 部署须先由网络隔离或认证反向代理保护。插件配置已要求非 loopback Sidecar 使用 HTTPS，并支持通过环境变量引用认证头。
- 在得到预发入口前，不修改个人 Gateway、不注册厂商生产回调、不发送真实用户消息，也不把本地签名 fixture 当成厂商实网证据。
- 每项记录宿主/插件版本、候选包 SHA-256、平台测试租户、时间、请求/回执关联 ID、重启前后状态和脱敏日志。缺失的项保持待验收。
